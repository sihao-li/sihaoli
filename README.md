# Si Hao Li Modern Academic Site

Static prototype for a more distinctive academic website: editorial research dossier, interactive presentation map, sober institutional identity, vendored Three.js, direct WebGL2, and Canvas 2D.

The original Hugo/PaperMod repository at `C:\Users\Si Hao\Documents\GitHub\sihaoli` is not modified.

## Quick Start

```bash
npm run build
npm start
```

Preview:

```text
http://localhost:4173
```

## Public Routes

- `/`
- `/publications/`
- `/talks/`
- `/teaching/`
- `/tutorials/`
- `/conference/`

The top navigation `CV` link opens `/public/cv.pdf` directly.

`Resources` and `Past` were removed from the public experience. Their old data/assets may remain locally as archival material, but they are not linked or generated by the public build.

## Interactive Layer

- Three.js: subtle research-theme graph on the homepage.
- WebGL2: quiet network background, disabled under reduced motion.
- Canvas 2D: compact publication/talk motion on the homepage.
- SVG map: talks and conference mode use clickable, keyboard-accessible map points.
- MathJax: local vendored MathJax is loaded only on pages that contain TeX formulas.
- Data Viz: the Top 5 Econ visualization is now a self-hosted static app using `public/data/top5-econ.csv`, not a Streamlit embed.
