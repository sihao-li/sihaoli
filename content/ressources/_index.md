# Economics Resources

## 📝 How to Write & Read an Economics Article

- **[How to Write an Economics Article (Hal Varian)](https://people.ischool.berkeley.edu/~hal/Papers/how.pdf)**  
  A classic by Hal Varian outlining a clear model for structuring and writing economics papers—highly recommended by Marc Bourreau.

- **[LaTeX Paper Writing Tips](https://github.com/guanyingc/latex_paper_writing_tips)**  
  A curated set of best practices and tips for writing academic papers in LaTeX, covering layout, formatting, and organization.

- **[Working Paper Template (FabienPetitEconomics)](https://github.com/FabienPetitEconomics/WorkingPaperTemplate)**  
  A ready-to-use LaTeX template for economics working papers, with standardized formatting and sample sections.

- **[How to Read an Econometrics Paper](https://www.econometrics.blog/post/how-to-read-an-econometrics-paper/)**  
  A step-by-step guide to effectively analyze an econometrics article and extract its key insights.

## 📊 Econometrics & Data Science

- **[causalQual (R)](https://github.com/riccardo-df/causalQual)**  
  An R package for causal inference.

- **[QuantEcon Lectures (Python)](https://quantecon.org/lectures/)**  
  Interactive Python lectures covering econometrics and quantitative modeling fundamentals.

- **[Coding for Economists (A. Turell)](https://aeturrell.github.io/coding-for-economists/intro.html)**  
  A comprehensive Python tutorial focused on data science and econometric applications.

- **[Sciencescape (Medialab)](https://medialab.github.io/sciencescape/)**  
  A platform from the Medialab offering tutorials on data analysis and text mining techniques.

- **[Inference Causale (in French)](http://inference-causale.com/index.html)**  
  A French-language resource dedicated to causal inference methods and use cases.

- **[easystats (R)](https://easystats.github.io/easystats/)**  
  A suite of advanced R packages for statistical analysis and model interpretation.

- **[Causal Inference Mixtape](https://mixtape.scunning.com)**  
  Scott Cunningham’s practical reference for hands-on causal inference methods.

- **[DiD Digest (Substack)](https://diddigest.substack.com)**  
  The go-to blog on Difference-in-Differences methods, with case studies and updates.

- **[Recent Advances in Applied Micro Methods (C. Cai)](https://christinecai.github.io/PublicGoods/applied_micro_methods.pdf)**  
  A PDF overview of the latest developments in applied microeconometrics techniques.

- **[Double Machine Learning Tutorial (dm13450)](https://dm13450.github.io/2021/05/28/Double-ML.html)**  
  A hands-on tutorial on the Double Machine Learning method for causal inference.

## 📈 Data Visualization

- **[EconGraphs](https://www.econgraphs.org)**  
  A collection of interactive charts to illustrate classic economic concepts.

- **[Interactive IO Graphs (Toxvaerd)](https://sites.google.com/site/toxvaerd11/home/interactive-graphs-for-io)**  
  Interactive visual tools tailored to Industrial Organization theory.

- **[bbplot (R)](https://github.com/bbc/bbplot)**  
  An R package for creating journalistically styled data visualizations inspired by BBC graphics.


## 🤖 LLM & AI for Social Science

- **[zeroshot-classifier (MoritzLaurer)](https://github.com/MoritzLaurer/zeroshot-classifier)**  
  A zero-shot NLI implementation for classification tasks in computational social science.

- **[Computational Social Science (CNRS – IPP)](https://www.css.cnrs.fr)**  
  The CSS  at IPP, offering tutorials and resources on computational social science.

- **[llm2vec (McGill-NLP)](https://github.com/McGill-NLP/llm2vec)**  
  Tools to convert decoder-only LLM architectures into encoder formats for NLP tasks.

- **[ollama-r (Hauselin)](https://github.com/hauselin/ollama-r)**  
  Integration of open-source LLMs within R.

- **[Quanteda Tutorials](https://tutorials.quanteda.io)**  
  Interactive tutorials for the `quanteda` R package, specializing in quantitative text analysis for social science research.

## 🏭 Industrial Organization

- **[Platform Strategies (Paul Belleflamme)](https://paulbelleflamme.substack.com/about?utm_source=subscribe_email&utm_content=learn_more)**  
  A Substack providing in-depth analyses and case studies on digital platform strategies.

- **[Topics in Digital Economics/Industrial Organization (Paul Belleflamme)](https://www.youtube.com/@topicsindigitaleconomics7066/videos)**  
  A video channel covering Industrial Organization and digital economics topics.

- **[Handbook of Dynamic and Empirical IO (V. Aguirregabiria)](http://aguirregabiria.net/wpapers/book_dynamic_io.pdf)**  
  Handbook on dynamic and empirical methods in Industrial Organization.


## 🌍 Macroeconomics

- **[PhD Macro Book](https://phdmacrobook.org/tableofcontents/)**  
  A free handbook for macroeconomics PhD students, covering theory, models, and applications.
